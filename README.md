# Controle de Manutenção de Interfones

Aplicação web para cadastro, acompanhamento e conclusão de incidentes de interfones.

## Funcionalidades
- Cadastro de incidentes e protocolo automático
- Filtros por status e bloco
- Registro do prestador e serviço executado
- Status de pendência, manutenção, retorno e resolução
- Histórico de chamados concluídos
- Layout responsivo

## Como executar
Abra `index.html` no navegador. Para publicar, use o GitHub Pages com a branch `main` e a pasta raiz `/`.

## Armazenamento atual
Os dados ficam no `localStorage` do navegador. Eles não são compartilhados entre dispositivos e podem ser perdidos se os dados do navegador forem apagados.

## Segurança
Não cadastre informações sensíveis nesta versão de demonstração e não inclua senhas, tokens ou arquivos `.env` no repositório.
