# Manual do usuário

## Cadastrar incidente
1. Acesse **Novo incidente**.
2. Preencha cliente, bloco, apartamento e observação.
3. Clique em **Cadastrar incidente**.

## Registrar manutenção
1. Acesse **Acompanhamento**.
2. Localize o protocolo.
3. Clique em **Iniciar** e depois em **Atualizar**.
4. Informe o prestador, a solução e a observação do serviço.
5. Clique em **Salvar retorno**.

## Consultar histórico
Acesse **Histórico** para visualizar os serviços resolvidos.

## Limitação
Os dados ficam salvos somente no navegador utilizado.
